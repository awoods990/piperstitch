Stripe fees & refunds

Each paid invoice's fee is booked the moment Stripe reports it. This pulls Stripe's full balance history for the last few months — every processing fee, Stripe's own billing, and refunds — so nothing is missed. Safe to run any time; nothing is counted twice.

Recurring monthly bills

Hosting (Railway), email (Postmark), the domain, software — anything billed monthly. Each is booked automatically into every month it covers. Those services don't publish invoices through an API, so set the amount here and adjust it when a bill differs.
